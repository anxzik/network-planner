# Product Info: Hardware Library

**Feature**: Hardware Library
**Created**: 2026-09-02
**Status**: Draft

## Overview

Network Planner arrives with 131 pieces of equipment built into it. If the
switch sitting in your rack is not one of them, you cannot plan with it, and
nothing you define can be handed to anyone else. This feature gives the
catalogue to the person using it: add the equipment you actually own, draw it
with the symbols your organisation uses, and pass a set to a colleague as a
file. Every part of a plan places hardware, which is why this comes first.

## What is Changing

- Equipment the application has never heard of can be added.
- A set of definitions exports to a file and imports elsewhere.
- Your own symbols replace the ones that shipped.
- Searching and filtering find one appliance among several hundred.
- All 131 existing appliances stay exactly as they are.
