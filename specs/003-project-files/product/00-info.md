# Product Info: Project Files

**Feature**: Project Files
**Created**: 2026-09-03
**Status**: Draft

## Overview

Today a network plan lives in one invisible storage slot inside the
application: one plan, no name, nothing to back up or send. This feature makes
a plan a file the person names and keeps, so it can move between machines, sit
in a backup, or go to a colleague. Existing work is carried across once, with
the original kept until its owner clears it. A plan also starts carrying its
own copies of the equipment definitions it uses, so it opens complete anywhere.

## What is Changing

- A plan becomes a named file, saved where you choose.
- Recent plans reopen from a list, no dialog.
- Existing work is offered a one-time move, original preserved.
- Plans open complete on machines that lack their equipment.
- A library correction is offered to plans, never forced.
- No failure destroys work you had not discarded.
